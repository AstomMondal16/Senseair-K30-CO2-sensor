# Senseair-K30-CO2-sensor
The K30 10,000ppm CO2 Sensor Module (030-8-0006) is a widely recognized and cost-effective solution, valued for its accuracy, durability, and low-maintenance design. Renowned for its reliability, it is extensively utilized in HVAC systems and indoor air quality (IAQ) applications. Furthermore, the sensor offers flexible programming capabilities with multiple output options, making it suitable for a wide range of OEM project requirements.
